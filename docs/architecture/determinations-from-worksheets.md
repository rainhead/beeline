# Determinations from worksheets

Part of Beeline's architecture notes; the index is in [AGENTS.md](../../AGENTS.md#architecture-overview).

`pnpm worksheets:fetch <drive-folder-id> [dir]` then `pnpm worksheets:load [dir] [db] [--manifest path] [--dry-run]` (`src/fetch-worksheets.ts`, `src/load-worksheets.ts`, beeline-pbk) is the `worksheet_import` channel: the Google Sheets volunteers determined their 2025-season specimens in, one copy of a template per volunteer (OBA Number, Sex/Caste, Family, Genus, Species), awaiting a transcription into the old database that mostly never happened — 18,704 settled-season rows fall on specimens with no determination at all ([docs/research/volunteer-worksheets.md](../research/volunteer-worksheets.md)). Three rules, decided with Peter on 2026-10-01. **Who** is a decision per file, never inferred: a sheet names no determiner, households and helpers break "the collector of its specimens", and Drive's last editor is usually the staff member who made the copy; so `data/worksheet-files.csv` (gitignored — it is a list of names) is refreshed on every load with the collector of most of each file's specimens proposed, and a file loads only once somebody writes a person reference (the overlay's `name:`/`inat:`) or `skip` beside it. **Which version**: volunteers copied sheets and kept going, so one specimen can stand in several of a determiner's files; copies that agree are one entry, and copies that disagree are held naming each other until somebody marks the stale one `skip`, because no clock says which is later thinking — the first version took the most recently modified file, which was an old copy touched in January, and creation time is wrong on other pairs. The same holds against the old system, which had a Determinations page of its own and kept no date: a row that would contradict the determiner's identification there, say less than it, or change its sex is held, and one that refines it loads (Peter, 2026-10-04, beeline-wuwm; on the sandbox none of the old values appeared in any of 34 Drive revisions of the sheets that disagreed with them). **Stray numbers** — typed by hand with no validation — are held when they land on a specimen the determiner did not collect, unless the manifest marks the file as determining for others, and are listed in the export's `held.csv` with the numbers either side — as is every row of a file nobody has decided about, so that file is everything that did not load. Sex/Caste maps to in-app entry's vocabulary (queen is a female gyne; a caste on a taxon without castes goes to the notes); `determined_on` stays empty, since a sheet has no clock but the file's. Loading again records nothing it holds, nothing a newer file already gave, and nothing changed in Beeline since the sheet was last edited. A store built before the channel existed refuses it by CHECK, which DuckDB cannot change: the loader says so before reading a file, and the answer is a reseed (ADR 0006). Like the Ecdysis load, a reseed does not carry what it recorded — run it again after one.
