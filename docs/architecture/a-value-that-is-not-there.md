# A value that is not there

Part of Beeline's architecture notes; the index is in [AGENTS.md](../../AGENTS.md#architecture-overview).

Absence is a component, `Absent` (`src/app/views/components/text.tsx`, proofed on `/design/components`), because the app drew it three ways — words on the record pages, a bare em dash on People and Jobs, an empty cell on the listings — and an empty cell is the worst of them: nobody can tell "there is none" from "it failed to load" (Nora, 2026-09-17). The rule: never blank; every absence carries its meaning as a `label` in the catalog's words, always read aloud; **spelled out** where the absence is the exception or tells the reader something ("not determined", "obscured", "No account", "outside"), and an **em dash** where the same absence repeats down a dense column and the words would be noise (a person with no membership recorded, a job that breached nothing, a name that is simply accepted in Ecdysis); secondary text either way, so it never reads as a value. A record page has the room and always spells. A count of 0 is a number, not an absence, and a links column with nothing to offer is `class="actions"` and may be empty, since it holds no value. **Do not type a "—" into a view or leave a nullable straight in a cell**: tests render each table against data with gaps in it and fail on any empty value cell.
