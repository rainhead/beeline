# Membership

Part of Beeline's architecture notes; the index is in [AGENTS.md](../../AGENTS.md#architecture-overview).

Membership has two shapes and one absence: a member atlas, or the umbrella program itself with no atlas — Master Melittology membership without a member atlas is real, so absence is reserved for "nobody has asked" (beeline-lcl). Since atlases were folded into programs (2026-10-31, beeline-ni5m.2) a `person_membership` row simply names a program: an atlas, which is a program with a region, or Master Melittology itself, code `MM`. The overlay field stays `home_atlas` and still takes `program` as the value for the second, since the file is the durable record and its vocabulary outlives the schema; the roster and the change log read "atlas or program" off whether the program has a region, so the screens and the log's recorded values did not change. Samples answer the same question geographically through `atlas_region`, where a row with a NULL atlas says "known region, no atlas covers it" and no row at all is what `qc_rule_place_unrecognised` fires on.
